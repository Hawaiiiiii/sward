# SGFX visual validation pack

Generated by `sgfx_ui_mirror.exe --screenshots-dir=...`

## What's here

10 PNG screenshots, one per in-scope screen / stage variant, rendered by
SGFX's native CSD compositor against the retail `extracted_assets/` tree:

| File | Screen | Notes |
|---|---|---|
| 01_title_intro.png | Title Intro | logo / press start screen |
| 02_title.png | Title Menu | NEW FILE / CONTINUE / SETTINGS / DLC / EXIT |
| 03_world_map.png | World Map | 3D globe stage select |
| 04_loading.png | Loading | Miles Electric loading panel |
| 05_stage_hud_day.png | Stage HUD - Day Sonic | rings / score / time / boost |
| 06_stage_hud_werehog.png | Stage HUD - Werehog | uses ui_playscreen_ev.yncp |
| 07_stage_hud_boss.png | Stage HUD - Boss | uses ui_playscreen_su.yncp |
| 08_pause.png | Pause | shared overlay (HudPause.cpp) |
| 09_results.png | Results | rank tally (CHudResult 4-state) |
| 10_hub.png | Hub | hub world UI (CHudTown) |

Each PNG is a 640×360 composite render -- the framebuffer pixels SGFX
would push to the SDL window when the orchestrator's current screen
matches the row.

## How to validate against UnleashedRecomp

1. Open each PNG in this directory.
2. Run UnleashedRecomp, navigate to the same screen.
3. Capture the screen (Win+PrintScreen or Win+Shift+S).
4. Side-by-side compare:
   - **Layout** -- panels in the right places?
   - **Asset choice** -- right textures, right CSD project (Day vs Werehog)?
   - **Text positions** -- captions / labels where they should be?
   - **Color / alpha** -- compositor blending matches?

Differences to expect (these are documented gaps, not bugs):

- **Text content placeholder.** Phase 346 wires stb_truetype to render
  the 10 known blank text-container scenes (`help_chara_*`,
  `help_text_area`, `progress`) with placeholder strings (e.g.
  `[help line 1]`). Retail uses pre-baked per-language text strips
  (`mat_*_en_*.dds`, `fte_ConverseMain_*.dds`). Wiring those is the
  remaining text-fidelity work.

- **Half-resolution canvas.** SGFX renders at 640×360 to keep the
  software CPU compositor interactive. SDL upscales to the window.
  UnleashedRecomp runs at native 1280×720; the layout is the same,
  the per-pixel resolution differs.

- **Top-left caption.** The `Stage HUD - Werehog` etc. text is a
  Phase 346 SGFX-only debug overlay. It does not appear in retail.

- **Blank quads / partial composition.** A handful of scenes have
  hide_flag set or 0-size subimages in the CSD; the renderer
  correctly skips them. They appear as gaps; UnleashedRecomp shows
  the same gaps when the corresponding retail code path doesn't
  populate the cast.

## Regenerating

```
bin_mirror\sgfx_ui_mirror.exe \
  --screenshots-dir=research_uiux\runtime_reference\out\sgfx_screen_validation
```

Headless (no SDL window opened); takes ~3 seconds.

## What's NOT in this pack

- Modal overlays (GeneralWindow, HelpWindow, SaveIcon, Status).
  These are reachable but only render when host opens them; not part
  of the screen graph as top-level destinations.
- Out-of-scope HUDs ported in Phase 348-351 (Mission, Boss vitality,
  Tornado Defense, MediaRoom). Those have state machines + smoke tests
  but no composite render here. The mirror could be extended to dump
  them too if needed.
- Full retail BGM. The mirror plays the embedded `g_installer_music`
  OGG vorbis blob through SDL_mixer's music slot to demonstrate the
  streaming path. A real port would register one OGG per cue from a
  host BGM bank.
